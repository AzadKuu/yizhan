## 1. 双击收集（COLLECT_TO_CURSOR）

- 步骤：开邮箱 / 驿站发货区 / 驿站收件区 / 寄件界面，把鼠标放在物品上**双击**（把同类物品收集到鼠标）。
- 预期：物品数量不变、不发生跨容器搬运；界面不动。
- 判据：`背包 + 界面` 总数守恒。

## 2. 邮箱保存期间禁止重开

- 步骤：开自己邮箱 → 拿走几件 → 关闭 → **立刻**再右键邮箱。
- 预期：提示「邮箱正在保存，稍等一下再打开～」；1 秒后再开，拿走的不见了、没拿的还在。
- 反例（修复前）：立刻重开能再看到早已取走的物品。

## 3. 回收仓库双人领取

- 步骤：A、B 同时开同一个回收仓库；A 点某件 → B 也点同一件。
- 预期：只有一个人拿到；另一人提示「这件东西已经被别人领走啦，刷新一下看看」，界面自动重绘。
- 判据：该件物品总量 +1，不是 +2。

## 4. 绑定邮箱的方块校验

| 对准的方块 | 预期 |
| --- | --- |
| 石头 / 泥土 / 圆石 | 拒绝：「这块方块不能当邮箱用…」 |
| 箱子 / 陷阱箱 / 木桶 / 任意潜影盒 | 允许绑定 |
| 别人已经绑过的箱子 | 拒绝并报对方名字 |
| 驿站方块 | 拒绝：「这块是驿站方块」 |
| 本服公共邮箱方块 | 拒绝：「不能占成私人邮箱」 |

- 另测：`/yz mailbox bind <玩家>`（管理员代绑）同样受这些校验。

## 5. 右键不再频繁查库

- 步骤：对着草地/石头连点右键 10 次；再对一个邮箱方块连点 5 次。
- 预期：无卡顿；日志无 SQL 异常。可选：开 spark 看主线程 SQL 时间片，或临时把 `debug: true` 观察。
- 说明：同一次右键主手/副手只处理一次；邮箱坐标、驿站、公共邮箱、自己的邮箱方块都进 5 秒内存快照。

## 6. 每日奖励幂等 + 失败回滚

- 步骤 A：同一账号在 1 秒内先后进入两台子服（或两台同时登录被踢来切去）。
- 预期：当天奖励只发一份（邮件里只有一封）。
- 步骤 B：把邮箱塞满 → 触发每日奖励 → 应走「暂存」提示；清理邮箱后「重新领取」能拿到。
- 步骤 C（可选）：发奖过程中临时断开数据库 → 日志报错，且当天领取标记被撤回（重启后还能再领）。

## 7. 权限

- 用没有 `yizhan.mail` 的组右键邮箱 → 提示无权限，不打开界面。
- 用没有 `yizhan.open` 的组右键驿站 → 提示无权限。

## 8. 回归（确认没碰坏原有功能）

- 寄物品给通讯录里的人 → 对方邮箱收到，提示文案正确。
- 寄 B 站链接（可写书流程）→ 收件侧「链接邮件」列表可见 → 正文页「打开链接」 → 聊天栏可点。
- 驿站发货 → 路由 → 到站 → 收件（`saveStationItems` 仍带版本校验，冲突提示正常）。
- `/yz unbind <驿站> [--force]` 护栏仍在。
